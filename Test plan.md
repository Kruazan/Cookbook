## Введение

Документ описывает план тестирования веб-приложения **«Кулинарная книга»** — менеджера рецептов с блочной структурой, режимом готовки и импортом.  
Цель — проверить соответствие реализации требованиям SRS, выявить дефекты до релиза.

**Основание:**  
- Анализ SRS: функциональные блоки, режим готовки, CRUD, поиск, импорт.  
- Исходный код:  
  - **Фронтенд (React + Redux):** `RecipeList.tsx`, `CreateRecipePage.tsx`, `CookRecipePage.tsx`, `AuthPage.tsx`, `StepIngredientCreateDTO.java` и др.  
  - **Бэкенд (Spring Boot):** `RecipeController.java`, `ProcessController.java`, `IngredientController.java`, `Recipe.java`, `Step.java`, `StepIngredient.java`.

<a name="items"/>

## Объект тестирования

**Фронтенд:** SPA на React с Redux (блочная структура рецептов, Drag&Drop, таймеры).  
**Бэкенд:** REST API на Spring Boot (JWT, CRUD рецептов, процессы, ингредиенты).

**Ключевые эндпоинты:**
| Эндпоинт | Описание |
|--------|---------|
| `/api/auth/login`, `/api/auth/register` | Аутентификация |
| `/api/recipes` | CRUD рецептов, поиск, фильтрация |
| `/api/processes` | Блоки шагов |
| `/api/ingredients` | Ингредиенты |
| `/api/steps` | Шаги с таймерами |
| `/api/step-ingredients` | Связь шаг ↔ ингредиент |

<a name="quality"/>

## Атрибуты качества (ISO 25010)

- **Функциональная полнота:** Блочная структура, таймеры, Drag&Drop.
- **Используемость:** Интуитивный UI, режим готовки, прогресс.
- **Надёжность:** Сохранение порядка блоков, восстановление после ошибок.
- **Безопасность:** JWT, защита от несанкционированного доступа.
- **Производительность:** Отклик ≤ 300 мс, обработка 100 рецептов.

<a name="risk"/>

## Риски

| Тип | Риск | Митigation |
|-----|------|------------|
| Технический | Ошибки Drag&Drop, потеря порядка блоков | Юнит-тесты, E2E |
| Функциональный | Таймер не срабатывает в фоне | Web Workers, уведомления |
| Безопасность | Доступ к чужим рецептам | Тесты авторизации |
| UI | Неправильный прогресс в режиме готовки | Cypress |
| Производственный | Ошибки импорта (парсинг) | Моки, интеграционные тесты |

<a name="features"/>

## Аспекты тестирования

**Функциональные:**
- Аутентификация (логин/регистрация)
- Создание рецепта из блоков (текст, ингредиенты, таймер)
- Drag&Drop блоков
- Режим готовки: пошагово, таймеры, прогресс
- CRUD рецептов
- Поиск и фильтрация
- Импорт по URL (если реализовано)

**Нефункциональные:**
- Производительность API
- Адаптивность UI
- Безопасность (JWT)

<a name="nonfunctional"/>

## Нефункциональные требования

- **Производительность:** Загрузка списка ≤ 1 сек; отклик API ≤ 300 мс.
- **Совместимость:** Chrome, Firefox, Edge (≥ 100).
- **Безопасность:** HTTPS, JWT, валидация.
- **Масштабируемость:** 100 одновременных пользователей.

<a name="approach"/>

## Подходы к тестированию

| Уровень | Инструменты |
|--------|------------|
| Юнит | JUnit (бэкенд), Jest (фронтенд) |
| Интеграционные | Supertest, Spring MockMvc |
| E2E | Cypress (режим готовки, Drag&Drop) |
| Ручное | UI, импорт, таймеры |
| Нагрузочное | k6 / JMeter |

<a name="env"/>

## Окружение и данные

- **Бэкенд:** Java 17, Spring Boot, H2 (test), PostgreSQL (dev)
- **Фронтенд:** Node.js 18+, Vite/React
- **Данные:** 10 пользователей, 50 рецептов, 200 блоков, 100 ингредиентов

<a name="acceptance"/>

## Критерии приёмки

- Все CRUD-операции работают
- Режим готовки: таймеры, прогресс, отметка шагов
- Drag&Drop сохраняет порядок
- Поиск и фильтрация точны
- Покрытие ≥ 85%
- Нет критических багов
